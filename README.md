# 🌿 CannaDupe

CannaDupe is a client-side Fabric mod for the CannaNetwork grindstone dupe workflow.

Made by **ItzOnlyFisher** 🍃

## Downloads

Download the jar matching your Minecraft version from the [GitHub Releases page](https://github.com/CannaNetwork/CannaDupe/releases).

Supported releases:

- Minecraft 1.20 through 1.20.6
- Minecraft 1.21 through 1.21.11
- Minecraft 26.1, 26.1.2, and 26.2

## Setup

1. Install Fabric Loader for your Minecraft version.
2. Download the matching CannaDupe jar from Releases.
3. Put the jar in your Minecraft `mods` folder.
4. Open a grindstone in-game. Use the CannaDupe controls there to choose the target item, set the grindstone, and start or stop the cycle.

## Notes

- Use the jar for your exact Minecraft version.
- CannaDupe is client-side.
- Follow your server's rules.

🌿 Have fun and stay green.
